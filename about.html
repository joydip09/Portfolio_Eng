About Me

I Build Things.
Then I Build Better Things.

I'm Joy, a Mechatronics Engineering student passionate about embedded systems, robotics, and intelligent devices. I enjoy designing firmware, building connected hardware, and creating modular software that bridges electronics with real-world applications. This portfolio documents not only finished projects, but also the engineering process behind them—from early prototypes and failed experiments to polished systems.

Philosophy

How I Think About Building

"Great engineering isn't about making something work once—it's about understanding why it works, designing it to be maintainable, and building it so future improvements become easier instead of harder."

🔬
Understand Before Optimizing

I start by building a working system, then study its behavior before improving performance, architecture, or usability.

📓
Document Everything

Good documentation makes projects easier to maintain, easier to share, and easier to revisit months later.

🔁
Design for Growth

I try to build software that can evolve. Clean architecture today saves countless hours when adding features tomorrow.
